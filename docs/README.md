## Orden recomendado para estudiar

1. Leer el reto en las guías del profesor.
2. Leer las secciones 1 y 2 de [GUIA_DEL_CODIGO.md](GUIA_DEL_CODIGO.md) con el proyecto abierto en VS Code.
3. Seguir los diagramas de secuencia (sección 4) mientras se prueba la app.
4. Repasar las preguntas del profesor (sección 9).
5. Usar [SUSTENTACION.md](SUSTENTACION.md) o el .docx para presentar.
